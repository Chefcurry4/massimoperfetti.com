# massimoperfetti.com

One static page: `index.html` (inline CSS, no build step), deployed by Netlify from `master`.

- `me.webp`: portrait
- `fonts/`: Instrument Sans, Chivo, Chivo Mono (SIL OFL, licenses alongside)

To preview locally, open `index.html` or run `npx serve .`.

The previous Astro site (bento wall, projects, writing, gallery, places) is preserved on the `astro-site` branch.
